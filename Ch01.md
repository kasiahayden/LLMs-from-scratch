## [Build an LLM from Scratch 1: Set up your code environment](https://www.youtube.com/watch?v=yAcWnfsZhzo&list=PLTKMiZHVd_2IIEsoJrWACkIxLRdfMlw11)

### Local setup
* Pick a python version a couple releases behind latest, so PyTorch and other scientific computing packages will be compatible.
* Use `uv` as a faster `pip` alternative.
* Create virtual environment with `venv`.
```console
brew install python@3.12
brew install uv
uv --version
# cd to desired dir, e.g. `rasbt` [code](https://github.com/rasbt/LLMs-from-scratch) clone
uv venv --python=python3.12
source .venv/bin/activate
uv pip install packages
uv pip install torch
```
* See [requirements.txt](https://github.com/rasbt/LLMs-from-scratch/blob/main/requirements.txt) for rasbt's full list of required libs and install all in a single command.

```console
uv pip install -r requirements.txt
```

* If you didn't clone the repo and create a venv in it, could instead pass the full link to requirements.txt which is `https://raw.githubusercontent.com/rasbt/LLMs-from-scratch/refs/heads/main/requirements.txt`.

```console
uv run jupyter lab
```
