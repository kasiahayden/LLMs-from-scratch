# LLMs From Scratch

This repository follows along with Sebastian Raschka's book, [*Build a Large Language Model (From Scratch)*](https://www.manning.com/books/build-a-large-language-model-from-scratch) (Manning), and his accompanying YouTube playlist, [*Build a Large Language Model (From Scratch)*](https://www.youtube.com/playlist?list=PLTKMiZHVd_2IIEsoJrWACkIxLRdfMlw11).

The goal is to build a GPT-style large language model from the ground up — tokenization, attention mechanisms, transformer architecture, pretraining, and fine-tuning — implemented step by step in PyTorch as I work through the book and videos.
